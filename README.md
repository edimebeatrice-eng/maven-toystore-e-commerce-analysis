# Maven Toy Store E-commerce Analysis

## 📊 Project Overview

This project analyses the performance of an e-commerce website using Power BI.

The analysis focuses on understanding website traffic, customer conversion, revenue performance, and the quality of traffic coming from different acquisition sources.

## 🎯 Business Questions

- How much traffic is coming to the website?
- Which sources bring the most visitors?
- Which traffic sources convert the best?
- How much revenue is being generated?
- Which sources generate the most revenue?
- How does traffic and conversion differ across devices?
- Which traffic sources provide the highest-quality customers?

## 🛠️ Tools Used

- Power BI
- Power Query
- DAX
- Data Modelling

## 📈 Dashboard

The dashboard is structured into five sections:

### 1. ATTRACT
Analyses website traffic and where visitors are coming from.

### 2. CONVERT
Measures how effectively website visitors are converted into customers.

### 3. MONETIZE
Analyses revenue performance and revenue generated from website traffic.

### 4. TRAFFIC QUALITY
Compares traffic volume, conversion rate, orders and revenue across acquisition sources.

### 5. INSIGHTS & RECOMMENDATIONS
Summarises the key findings and provides business recommendations.

## 🔎 Key Findings

- G-search generated the highest traffic volume.
- G-search generated the highest number of orders.
- G-search generated the highest revenue.
- B-search had the highest conversion rate.
- Overall conversion performance shows opportunities to improve the customer journey.

## 💡 Business Recommendations

- Continue investing in high-performing acquisition channels such as G-search.
- Investigate what makes B-search traffic convert at a higher rate.
- Improve the website journey from landing page to checkout.
- Analyze device-level performance to identify opportunities for improving conversion.
- Monitor revenue generated per session to evaluate traffic quality.
